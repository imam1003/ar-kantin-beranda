Pilih menu menggunakan tombol. Preview tetap dapat digunakan di MacBook meskipun WebXR tidak tersedia.

Cara menggunakan
  1. Pilih salah satu menu di tombol atas atau gunakan Sebelumnya/Berikutnya.
  2. Untuk mencoba AR, buka halaman melalui HTTPS di Chrome pada HP Android yang mendukung WebXR/ARCore.
  3. Tekan Mulai AR dan izinkan akses kamera jika diminta.
  4. Jika WebXR tidak didukung, gunakan preview menu di halaman ini; fitur preview tidak memerlukan AR.
Gerakkan HP perlahan untuk mencari permukaan, lalu sentuh layar untuk menempatkan menu.

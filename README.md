# AR Menu Kantin Beranda

Website menu dengan fitur augmented reality berbasis WebXR.

## Menjalankan

Buka situs melalui HTTPS agar browser dapat mengakses kamera:

<https://imam1003.github.io/ar-kantin-beranda/>

Gunakan Chrome di ponsel Android yang mendukung ARCore/WebXR, lalu izinkan
akses kamera saat diminta. Untuk pengujian lokal, gunakan `localhost`.
